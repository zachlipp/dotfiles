# Zach's `neovim` config

Welcome to the sicko zone. I have learned to love Lua. You can, too.

## Customizations
- I have mapped my keyboard's `CAPS LOCK` to  `escape`. This makes changing modes less awful.
- I configure leader as `,` and `localleader` as `\`. This works so well for me; give it a shot if you haven't.
