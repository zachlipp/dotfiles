# Zach's Neovim Config

I have learned to love Lua. You can, too.

## Customizations
- I have mapped my keyboard's `CAPS LOCK` to  `escape`. This makes changing modes less awful.
- I configure leader as `,` and localleader as `\`. This works so well for me; give it a shot if you haven't been using your shortcuts often.

## Layout

All of `lua/plugins/` is imported by `{ import = "plugins" }`, so any new file returning a spec table is picked up automatically.
